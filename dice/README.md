# ダイスタンブラー / Dice Tumbler

ダイスの上に立ち、足元のダイスを転がして目をそろえ、床へ沈める一人用パズル。
ブラウザだけで動きます（ライブラリ・画像・音声ファイルなし、HTML 1ファイル）。

**▶ Play: https://jumpk38.github.io/sites/dice/**

---

## これは何か

PlayStation『XI [sai]』（1998年・ソニー・コンピュータエンタテインメント）の
1人用ルールを解析し、**独自に再実装した習作**です。

- 原作の権利者とは一切関係がありません。
- 原作の画像・音声・コード・フォント等のアセットは一切使用していません。
- ゲームのルールやシステム自体は著作権の保護対象外であるという理解のもと、
  コード・グラフィック・UI はすべて新規に書き起こしています。
- 非商用の学習・習作目的で公開しています。

## 遊びかた

| | |
|---|---|
| **移動** | ダイスの上で方向キー。隣が空きマスなら足元のダイスが転がって上の目が変わる。隣にダイスがあれば乗り移るだけ |
| **押す** | 床にいるときは目の前のダイス1個をスライドさせられる（向きは変わらない） |
| **バニッシュ** | 上の目が n のダイスをタテヨコに n 個以上つなげると沈んで消える（沈みきるまで約5秒） |
| **チェイン** | 沈みかけのダイスも連結数に数える。同じ目を隣に持ち込むか、半分沈んだダイスに転がして重ねる（踏み潰し）と巻き込める |
| **ハッピーワン** | 1 は単独では消えない。沈みかけのダイスの隣に 1 を持ち込むと盤上の 1 が全部沈む |
| **復帰** | 床からは「生えかけ」か「半分沈んだ」ダイスにしか登れない。光っているマスが乗り場 |

モードは **エンドレス**（盤面が埋まるまで）と **タイムアタック**（3分間のスコアアタック）。

操作は **キーボード**（←↑↓→ / WASD、P=ポーズ、R=やり直し）と
**タッチ**（盤面スワイプ＋画面下の十字ボタン）の両対応です。

## ファイル構成

```
★ index.html               エントリ（tools/build.py が生成／直接編集しない）
★ manifest.webmanifest     PWA マニフェスト
★ sw.js                    オフライン用サービスワーカー
★ icons/                   アプリアイコン4点（tools/make_icons.py が生成）
  tumbler.html             ゲーム本体のソース。<head> を持たない body 断片
  tools/build.py           tumbler.html → index.html
  tools/make_icons.py      アイコン生成（依存ライブラリなし）
  .nojekyll                Jekyll 処理の無効化（使うならリポジトリのルートに置く）
```

★ が動作に必要なファイルで、この7点と本 README だけを公開ディレクトリに置いています。
ソースとビルドツールは手元にのみ残しています。

ゲームのロジックと見た目はすべて `tumbler.html` にあります。編集したら:

```bash
python3 tools/build.py
```

## ローカルで動かす

`index.html` はダブルクリックだけでも動きますが、サービスワーカーは
`file://` では登録されません。オフライン動作まで確認するなら:

```bash
python3 -m http.server 8000
```

→ http://localhost:8000/

## 更新を配るとき

`sw.js` はページ本体をネット優先で取りに行くので、通常は再訪時に自動で新しくなります。
アイコンやフォントまで確実に入れ替えたいときは `sw.js` の `CACHE = "dice-tumbler-v1"`
の版数を上げてください。

## 公開先

https://jumpk38.github.io/sites/dice/

`jumpk38/sites` リポジトリの `dice/` ディレクトリに、動作に必要なファイルだけを置いています。
更新するときは手元で

```bash
python3 tools/build.py
```

を実行し、`index.html` / `manifest.webmanifest` / `sw.js` / `icons/` を
`sites/dice/` にコピーして push します。

## iPhone / iPad で遊ぶ

Safari で開いて **共有 → ホーム画面に追加**。全画面のアプリとして起動し、
2回目以降は機内モードでも動きます（サービスワーカーがフォントごとキャッシュします）。

ファイルアプリに `.html` を保存してタップする方法は、プレビューで
JavaScript が動かないため機能しません。
